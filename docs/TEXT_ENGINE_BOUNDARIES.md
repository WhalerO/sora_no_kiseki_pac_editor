# 文本引擎能力与验证

本文记录 TBL/DAT 文本算法当前的实际能力、写回机制和验证证据。

## 使用方式

顶部提供两个互不依赖的全局选项：

- TBL 引擎：默认 `Kuro`，也可选择 `Legacy`；
- DAT 引擎：默认 `Legacy`，也可选择 `Kuro`。

该选择贯穿预览、单文件、批量、版本对比、暂存回读和 PAC 工作区。等长与非等长
替换都不需要额外授权。“允许启发式回退写入”只用于无法建立结构布局的异常文件，
不会限制正常的 `#TBL` / `#scp` 变长写入。

## 当前能力

| 文件 | Kuro | Legacy |
|---|---|---|
| `#TBL` | Schema + 通用记录引用发现；等长原位或变长字符串池重定位 | 使用同一完整文本/引用清单；SLOT 或变长重定位 |
| `#scp` DAT | 精确读取所有结构化字符串引用；直接剪接字符串池 | 使用同一精确 DAT 布局；SLOT 或直接剪接字符串池 |
| CLE 封装 | 读取并恢复 D9BA/F9BA/C9BA 层 | 读取并恢复 D9BA/F9BA/C9BA 层 |
| 无法识别的旧 DAT | 脚本反汇编/重编回退，实验性 | 原启发式尾池回退，实验性 |

## TBL 写回机理

TBL 写入不再按“数值相等”搜索和替换指针。解析阶段会记录每个真实 64 位外部
偏移字段的字节位置：已知 Header 来自 Schema，未知 Header 则依据完整记录列、
外部区间和 UTF-8 C 字符串结构发现。外部数组或纯偏移字段也进入重定位图，但不会
被误当成可编辑文本。

多个字段可以指向同一字符串，或指向同一 C 字符串的不同后缀。界面将重叠存储
合并为一个完整文本；写入时通过字节差异映射内部别名边界，再更新所有引用。这样
既不会漏掉短文本/标点文本，也不会把 NPC 外部二进制块中碰巧可打印的字节暴露为
文本。

`NPCParam` 的 160 字节 Sora1 布局新增了“纯外部偏移”字段类型：它参与重定位，
但不参与文本展示。这正是“解析所有文本”和“扫描所有可打印字节”的区别。

## DAT 写回机理

对于 `#scp`，解析器精确遍历脚本头、函数表、输入/输出、结构参数、脚本变量和
0x00–0x28 指令，记录每个 tagged string 指针的字段位置。可编辑文本包括代码
字符串、结构字符串、跨脚本名称、函数输入/输出和函数名；空字符串不显示。

变长保存只剪接末尾 C 字符串池，并重写这些已记录的 32 位 tagged pointer。
函数体、指令宽度、跳转和非文本操作数不经过汇编器，因此保持原字节。保存后仍会
重新解析全部文本，并通过非文本脚本结构指纹复核。KuroTools 的脚本重编仅作为
无法建立精确二进制布局时的显式回退。

## “调查‘震源地’”回归

故障根因是旧 TBL REPACK 在固定记录区搜索与字符串偏移数值相同的普通整数。
`t_quest.tbl` 的任务 ID 因此被当作指针重定位，支线名称跳到了其他章节。

当前实现只改写解析时记录的具体字段位置。使用 `BUG排查/原版/table_sc.pac` 中的
真实条目验证：`调查“震源地”` 位于 `QuestTitle[11].quest_name`；在前方文本强制
增长 480 字节后，Kuro `pool-repack` 与 Legacy `repack` 都保持该任务名唯一且不变。
合成回归还专门构造了“任务 ID 数值恰好等于字符串偏移”的碰撞，确认普通 ID 字段
不会被写入。

- `table_sc`：237 个 TBL 全部解析成功；Kuro 与 Legacy 得到完全相同的 99,603 个
  非空文本存储；每个文件内的全部非空文本在同一轮中同时增长 1 字节，两个后端
  均为 228/228 成功，另 9 个文件没有非空文本；
- `script_sc` / `script_tc` / `script_kr`：共 2,367 个 DAT、1,034,429 个非空
  字符串；每个文件内的全部非空字符串在同一轮中同时增长 1 字节，精确引用重定位
  和重新解析全部成功，错误为 0；
- D9BA 包装的真实 TBL/DAT 已分别通过 Kuro 与 Legacy 的变长保存和重新载入；
- 自动化回归包含数值碰撞、SLOT 定长覆盖、内部字符串别名、独立 TBL/DAT 引擎
  路由和 CLE 保持验证。

## 仍需保留的边界

- 非 `#scp` 的旧 DAT 回退仍是启发式能力，默认不授权写入；
- 新游戏版本若改变 Header、指令或容器格式，需要新增语料重新认证；
- 全文与结构回读不能替代最终游戏运行测试，正式发布仍应保留原 PAC 并另存回包。

这些边界不再用于禁止已建立结构关系的正常功能；它们只描述尚未获得格式证据的
回退路径。
