## 使用

下载 Windows x64 onedir ZIP，完整解压后运行 `TIS_Retext.exe`，无需安装 Python。
`_internal` 是必要的运行依赖，不能只取出 exe。缓存默认位于 exe 旁的
`TIS_Retext_Data/`，请将程序放在可写的非系统盘目录。

压缩包的 `mappings/常用文本替换_不含金.json` 与 Release 的
`common-text-replacements-no-zin.json` 附件内容相同。
它是 30 条常用替换规则的参考方案，不包含“金”的替换规则，也不包含章节图片。
在“批量”页导入映射表，添加 script_sc/table_sc 的处理范围，扫描并核对命中，
执行替换后导出对应 PAC。导入前请保存自己的映射，使用前请备份游戏原文件。

## 更新

- 后台正文搜索逐步显示命中，优化较大资源范围的操作响应。
- 优化 DAT 指针扫描修复、差异文本展示及 PAC 导出后的状态判断。
- 支持读取 LZ4 包装的 DDS，修复相关图片、模型纹理和字体图集预览。
- Windows Per-Monitor V2 DPI 支持，改善高缩放比例及不同 DPI 显示器下的显示。
- 便携缓存位于程序旁，默认不再占用系统盘 AppData。
- 附带参考映射、MIT 许可证和第三方组件说明。
