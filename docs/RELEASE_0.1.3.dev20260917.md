# 0.1.3.dev20260917 修复说明

本版针对部分存放环境打开 PAC 时，缓存目录出现
`.lock-…tmp -> lock.json` / `WinError 1` 的问题。

## 修改

- Windows 锁发布改用不覆盖现有文件的重命名，不再调用硬链接；锁信息完整写入后才发布。
- 使用短时 Windows 进程间互斥保护失效锁回收、发布及释放；保留活跃锁保护、所有权校验和异常退出后的恢复能力。
- 归属不明或无法解析的锁保守保留，不自动删除用户缓存。
- 缩短随机会话目录与临时文件名；缓存依旧默认在程序旁边，不自动迁移到系统盘。
- 缓存操作失败时明确提示目录和系统原因，给出移动完整工具或指定数据目录的方法。

没有改变文本替换规则、PAC 格式算法、游戏版本识别或游戏原始文件。

## 使用范围

中文路径和普通网盘下载目录不被一概禁止。此次修复移除了 Windows 硬链接要求，
但不会让只读目录、未下载的在线占位文件或任意第三方虚拟文件系统自动具备正常读写能力。
也不承诺任意长度的路径都能使用；路径较短的本地目录仍是较稳妥的选择。

请完整更新工具目录，保留 `_internal`。数据目录配置方法见
[编辑器使用指南](EDITOR_GUIDE.md#工具放在哪里)。源码版本与已上传下载包可能不同，
下载前以 Releases 中对应附件的版本为准。

## 构建脚本修正

一键入口保持调用者的 PowerShell 版本，并检查虚拟环境创建、依赖安装和打包的退出码。
打包自检 JSON 显式按 UTF-8 读取，修复中文路径在 Windows PowerShell 5.1 中被错误解码的问题。
构建前清理旧的完成标记，自检失败不会打印成功或留下上次的构建清单。
`build.ps1 -SkipDependencyInstall` 可复用已安装依赖；两种 PowerShell 均有回归覆盖。

## 验证范围

回归覆盖硬链接 API 被拒绝时正常取得锁、完整发布、并发抢锁、并发回收失效锁、
子进程异常退出恢复、错误令牌释放、未知锁保留、写入失败清理和短会话路径。
故障注入与本地测试不等于在反馈者的具体磁盘或网盘软件上完成实测。

本地 CPython 3.14.3 验证：

- 编译、依赖检查、287 项回归（274 项通过，13 项可选本地语料测试跳过）及合成文本/PAC 烟测通过。
- 当前 the 2nd 正式版资源中的 `t_books.tbl`、`mp0000.dat` 完成变长保存、重复保存、全文回读及顺序批量替换检查。
- 当前 `image_sc.pac` 完成图片替换、插入、提取及重建；未修改的条目与原资源保持一致。
- 上述集成检查在主进程硬链接 API 被强制拒绝时通过；原始 PAC 内容未修改，临时产物清理完成。
- 原先临时锁文件总路径 269 字符的边界场景，在缩短文件名后通过。

这些结果不表示验证了正式版的全部剧情或所有资源类型，也不表示已上传新可执行文件；
远端附件仍以实际发布记录为准。
