# 编辑器替换映射

`常用文本替换_不含金.json` 可在 TIS_Retext 的“批量”页，使用“导入映射表”导入。
选择需要处理的 script_sc.pac、table_sc.pac 范围，查找并核对命中后再执行替换。

- 来源：TIS_Retext_Patcher 当前内置补丁；与 Voice_Patcher 的文本规则一致。
- 共 30 条，默认全部启用，涵盖人名、战技、魔法和章节名文字。
- 完整排除“金”补丁：不包含“阵先生”、整行“阵”及其精确全文清单。
- 编辑器按行顺序替换，因此肯帕雷拉的长句修正放在短姓名规则之前。
- “雷光→闪电光束”启用全匹配，避免改动“雷光斩”“审判雷光”等包含该词的文本。
  编辑器的全匹配要求整个文本单元相同，比 Patcher 的独立整行匹配更窄；
  若目标是多行文本中的单独一行，需要另行核对，不能简单关闭全匹配后全选替换。
- 章节名这里只改文字，不会处理 image_sc.pac 中的四张 DDS；图片请使用 Patcher
  对应章节选项，或通过包内文件管理单独替换。
- 四个方术沿用现有补丁中的“满渍寒光生铁衣”，保留既有字库兼容用字。

导入会替换编辑器当前映射表；如果已有自己的规则，请先导出备份。
